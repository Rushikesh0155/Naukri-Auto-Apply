      01Set it up with an AI

      Let an AI do the setup for you. Paste this into an assistant that can run commands on your PC, like Claude Code or Cursor, and it does the work and only hands you the parts it can't, like signing in. A regular chat AI works too, it just gives you commands to paste.

      Setup prompt 
      Help me install Naukri Autopilot, a tool on my PC that keeps my Naukri profile fresh by re-uploading my resume and rotating my headline on a schedule.

If you can run commands on my PC, do the setup yourself. If you can't, give me one exact command at a time to paste into Command Prompt, and wait for the result before moving on. Only ask me to do the things you can't do. Keep your messages short.

Setup:
1. Find the Naukri Autopilot folder (ask me where it is if you can't find it) and work from inside it.
2. Check that Python 3.9 or newer is installed with py --version. If it isn't, tell me how to get it from python.org, and remind me to tick "Add python.exe to PATH" in the installer.
3. Run setup.bat. The first time takes a few minutes.
4. Make sure there's a resume PDF in the Resume folder. If there isn't one, ask me to add it.
5. Run dashboard.bat. The dashboard opens at http://127.0.0.1:8777.
6. Ask me to press "Sign in to Naukri" and log in myself in the window that opens.
7. Ask me to press "Run update", then confirm with me that my Naukri profile shows updated today.
8. Ask me to set the schedule to 24 hours on the Configuration page.

Rules:
- Never ask for my Naukri password or OTP. I type those myself.
- If something fails, read the error, fix it if you can, and explain in one line what went wrong.
- Don't change any files except what setup needs.

After that, stay on to help with things like a failed run or an expired session.

      02Getting started

      Three things and you are done. Drop your resume PDF into the Resume folder, hit Sign in to Naukri on the Home page, then pick a schedule on this page.

      Do one manual run first. Press Run update, give it a minute, then open your Naukri profile and check it says "last updated: Today". Once you have seen that work, you can trust the schedule.

      The dashboard does not need to stay open. Runs happen on their own. Come back here when you want to check on it.

      If Windows blocked the files. Anything downloaded from the internet gets marked, and that mark can stop the zip from extracting properly. Right-click the zip, pick Properties, tick Unblock at the bottom, press OK, then extract it again.

      The first time you run setup.bat you may get a blue "Windows protected your PC" box, because the file is new and unsigned. Click More info, then Run anyway.

      03How often to run it

      Once a day is the sweet spot. Recruiters see the same "updated today" whether you refreshed once or ten times, so extra runs get you nothing.

      Twelve hours is the floor. Going faster than that does not help you and starts to look like a script rather than a person, which is the one thing worth avoiding.

      Use this on your own account only. Naukri is not keen on automation, so keep the interval sensible. Your account is the thing worth protecting here.

      04The browser window

      A real browser has to open, because Naukri blocks the invisible kind outright. It is parked way off the edge of your screen, so you will never see it, and it closes itself when the run finishes.

      It uses the browser setup.bat downloaded. If that one ever refuses to start, it falls back to Edge, and the log says which it used. Nothing else changes.

      If you want to watch one happen, put this in your .env file:

      HEADFUL=1

      05Your password

      It never sees it. You sign in yourself, once, in a real browser window, OTP and all. Only the session cookies get saved, and they sit in a file on your machine.

      Every successful run refreshes those cookies, which keeps the session going for weeks. When it does run out, the dashboard says "Sign in needed" and you do it again.

      06The two updates

      Resume re-upload is the one that does the work. It uploads the same PDF again, the timestamp resets, you move back up the list. Leave this on.

      Headline rotation needs at least two variants, because saving the same headline twice does nothing at all. Naukri tidies up spacing before it stores anything, so a whitespace tweak gets stored as no change.

      Two genuinely different versions means every run writes something new. Keep them aimed at the same roles and change a word or two, so the keywords recruiters search on stay where they are.

      Both are optional and independent. If one breaks because Naukri moved something, the other still does its job.

      07When something breaks

      Open Captures. Every failed run saves a screenshot of the exact page it was looking at, which usually makes the reason obvious straight away.

      "Sign in needed" means the session ran out. Sign in again from the Home page, that is all.

      "Access Denied" is Naukri's bot protection, not your login. Leave it a few hours and try again.

      Nothing ran overnight is usually your PC being asleep or off. Runs only fire while you are logged in, and a missed slot catches up shortly after you are back. Check History to confirm.

      08Removing it

      Set the schedule to Off on the Configuration page, switch off Start on login, then delete the folder. Those two switches are the only things that touch anything outside it.

      What they remove are two entries in Windows Task Scheduler, called "Naukri Autopilot Update" and "Naukri Autopilot Dashboard". If you ever want to check, open Task Scheduler and look in the top level list.

      About

      Naukri Autopilot for Windows.

      A small tool that keeps your Naukri profile looking fresh, so recruiters keep finding you.

      THE PROBLEM

      Naukri sorts recruiter searches by when a profile was last updated. If yours has not changed in a week it quietly slides down the list, however good it is.

      The fix is to open Naukri and change something small. Takes a minute, and it is very easy to forget.

      WHAT IT DOES

      It does that minute for you, every day.

      A browser opens off-screen, signs in with your saved session, re-uploads the same resume, grabs a screenshot as proof and closes. About a minute, and you never see any of it.

      The dashboard is where you keep an eye on it. Whether the last run worked, when the next one is due, and a screenshot from each one so you can see it happened instead of hoping.

      HOW IT IS BUILT

      Python and Playwright, all of it on your machine. The dashboard is plain HTML with no build step. Everything lives in the folder: your resume, your session, your logs. Nothing gets uploaded anywhere and there is no account to make.

      It is deliberately small. One dependency, files you can actually read, and a folder you can delete when you are done with it.
